# 海尔 A6 `haier.a6`

内置协议 `haier.a6` 按这组采集实现。来源：`artifacts/ir_capture/20261101_141745/samples/01/`。292 帧均为 229 脉冲，14 字节加法校验全部通过；16℃/30℃边界会重发当前状态，因此温度限制为 16–30℃（4 bit 字段本身可到 31℃）。载波按 38 kHz 假设。

- 双头约 `3064/3114 + 3064/4558 µs`，112 bit MSB-first；字节 13 为字节 0..12 的加法和。
- 时序取实测中位数并按 10 µs 取整：头 `3060/3110 + 3060/4560 µs`，标记 `510 µs`（结尾标记实测约 484 µs，同样取 510），0/1 位空格 `590/1700 µs`。
- 字节 0 固定 `A6`；字节 1 高半字节为 `temperature - 16`，低半字节的下/中/上/扫风为 `0/2/A/C`。
- 字节 4 bit6 为电源；自动和制热另置 bit7。
- 字节 5 高三位的自动/低/中/高风为 `A0/60/40/20`；睡眠另置 bit3。
- 字节 7 高三位的自动/制冷/除湿/制热/送风为 `00/20/40/80/C0`；字节 8 bit7 也是睡眠状态。
- 字节 12 动作码：温度加/减、方向与扫风、风速、睡眠与电源、模式分别为 `00/01/02/04/05/06`。
- BASIC 编码器使用中间固定风向 `2` 和完整状态更新码 `06`；动作码选择仍是无历史接口的策略。
