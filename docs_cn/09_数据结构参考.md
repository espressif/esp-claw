# 09 数据结构参考手册

## 9.1 claw_core — 请求与响应

### `claw_core_request_t`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `request_id` | `uint32_t` | 是 | 唯一请求 ID（调用方生成） |
| `flags` | `uint32_t` | 否 | 位标志组合 |
| `session_id` | `const char *` | 否 | 会话标识符（NULL = 无状态） |
| `user_text` | `const char *` | **是** | 用户输入文本（不可为空） |
| `source_channel` | `const char *` | 否 | 来源通道（如 "telegram"） |
| `source_chat_id` | `const char *` | 否 | 来源聊天 ID |
| `source_sender_id` | `const char *` | 否 | 发送者 ID |
| `source_message_id` | `const char *` | 否 | 来源消息 ID |
| `source_cap` | `const char *` | 否 | 发起此请求的能力 ID |
| `target_channel` | `const char *` | 否 | 强制指定回复通道 |
| `target_chat_id` | `const char *` | 否 | 强制指定回复聊天 ID |

**flags 常量：**
- `CLAW_CORE_REQUEST_FLAG_PUBLISH_OUT_MESSAGE` = bit 0
- `CLAW_CORE_REQUEST_FLAG_SKIP_RESPONSE_QUEUE` = bit 1
- `CLAW_CORE_REQUEST_FLAG_USER_INTERRUPT` = bit 2

### `claw_core_response_t`

| 字段 | 类型 | 说明 |
|------|------|------|
| `request_id` | `uint32_t` | 对应的请求 ID |
| `status` | `enum` | `OK` 或 `ERROR` |
| `completion_type` | `enum` | 目前只有 `DONE` |
| `target_channel` | `char *` | 回复通道（堆分配，需 free） |
| `target_chat_id` | `char *` | 回复聊天 ID（堆分配，需 free） |
| `text` | `char *` | 成功时的答复文本（堆分配） |
| `error_message` | `char *` | 失败时的错误描述（堆分配） |

### `claw_core_config_t`（初始化配置）

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `api_key` | — | LLM API 密钥（必填） |
| `backend_type` | — | 后端类型（必填） |
| `model` | — | 模型名称（必填） |
| `base_url` | — | API 基础 URL |
| `system_prompt` | — | Agent 系统提示词（必填） |
| `timeout_ms` | — | LLM HTTP 超时 |
| `max_tokens` | — | 最大生成 token |
| `task_stack_size` | 8192 | Agent 任务栈大小 |
| `task_priority` | 5 | 任务优先级 |
| `task_core` | tskNO_AFFINITY | CPU 核绑定 |
| `max_tool_iterations` | 10 | 最大工具调用轮次 |
| `request_queue_len` | 4 | 请求队列长度 |
| `response_queue_len` | 4 | 响应队列长度 |
| `max_context_providers` | — | context provider 容量上限 |
| `persist_session` | NULL | 会话持久化回调 |
| `request_gate` | NULL | 请求门控回调 |
| `on_request_start` | NULL | 请求开始通知回调 |
| `collect_stage_note` | NULL | 阶段注记收集回调 |
| `call_cap` | NULL | 能力调用分发函数（通常是 `claw_cap_call_from_core`） |

## 9.2 claw_cap — 能力系统

### `claw_cap_descriptor_t`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `const char *` | 能力唯一 ID（LLM 调用时使用） |
| `name` | `const char *` | 显示名称 |
| `family` | `const char *` | 能力族（分组标识） |
| `description` | `const char *` | 功能描述（注入 LLM 工具定义） |
| `kind` | `enum` | `CALLABLE`/`EVENT_SOURCE`/`HYBRID` |
| `cap_flags` | `uint32_t` | 标志位（`CALLABLE_BY_LLM` 等） |
| `input_schema_json` | `const char *` | JSON Schema 字符串 |
| `init` | `fn ptr` | 初始化钩子 |
| `start` | `fn ptr` | 启动钩子 |
| `stop` | `fn ptr` | 停止钩子 |
| `execute` | `fn ptr` | 执行函数 |

### `claw_cap_group_t`

| 字段 | 类型 | 说明 |
|------|------|------|
| `group_id` | `const char *` | 组 ID |
| `plugin_name` | `const char *` | 插件名称 |
| `version` | `const char *` | 版本 |
| `descriptors` | `claw_cap_descriptor_t *` | 描述符数组 |
| `descriptor_count` | `size_t` | 描述符数量 |
| `plugin_ctx` | `void *` | 组私有上下文 |
| `group_init/start/stop` | `fn ptr` | 组级生命周期钩子 |

### `claw_cap_call_context_t`

| 字段 | 说明 |
|------|------|
| `request_id` | 当前 Agent 请求 ID |
| `session_id` | 会话 ID |
| `channel` | 回复通道 |
| `chat_id` | 回复聊天 ID |
| `source_cap` | 调用方能力 ID |
| `correlation_id` | 关联 ID |
| `caller` | `SYSTEM`/`AGENT`/`CONSOLE` |

## 9.3 claw_event — 事件系统

### `claw_event_t`

| 字段 | 大小 | 说明 |
|------|------|------|
| `event_id` | 48 | 唯一事件 ID |
| `source_cap` | 32 | 产生事件的能力 ID |
| `event_type` | 32 | 事件类型（"message", "trigger", "schedule"等） |
| `source_channel` | 16 | 来源通道 |
| `target_channel` | 16 | 目标通道 |
| `source_endpoint` | 64 | 来源端点 |
| `target_endpoint` | 96 | 目标端点 |
| `chat_id` | 96 | 聊天 ID |
| `sender_id` | 96 | 发送者 ID |
| `message_id` | 96 | 消息 ID |
| `correlation_id` | 96 | 关联 ID |
| `content_type` | 24 | 内容类型 |
| `timestamp_ms` | int64_t | 时间戳（毫秒） |
| `session_policy` | enum | 会话策略 |
| `text` | `char *` | 文本内容（堆分配） |
| `payload_json` | `char *` | JSON 负载（堆分配） |

## 9.4 claw_memory — 记忆系统

### `claw_memory_item_t`

| 字段 | 大小 | 说明 |
|------|------|------|
| `id` | 40 | UUID-like 唯一 ID |
| `source` | 16 | 来源标签（"manual"/"auto"/"session"） |
| `content` | 256 | 记忆内容正文 |
| `summary_ids` | 3 × uint16 | 关联摘要 ID 列表 |
| `summary_id_count` | uint8 | 实际摘要数量（最多 3） |
| `tags` | 96 | 自由标签（逗号分隔） |
| `keywords` | 128 | 关键词（逗号分隔） |
| `created_at` | uint32_t | 创建时间（Unix 秒） |
| `updated_at` | uint32_t | 最后更新时间（Unix 秒） |
| `access_count` | uint16_t | 被 recall 访问次数 |
| `deleted` | uint8_t | 软删除标志 |

### `claw_memory_query_t`

| 字段 | 说明 |
|------|------|
| `summary_labels` | 摘要标签字符串数组 |
| `summary_label_count` | 标签数量（0 = 不按标签过滤） |
| `limit` | 最大返回条目数（0 = 使用默认值 8） |

### `claw_memory_config_t`

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `session_root_dir` | — | 会话历史目录路径（必填） |
| `memory_root_dir` | — | 长期记忆目录路径（必填） |
| `max_message_chars` | 4096 | 单条消息最大字符数 |
| `max_tool_iterations` | 10 | 自动提取 LLM 调用的最大轮次 |
| `llm` | — | 自动提取使用的 LLM 配置 |
| `enable_async_extract_stage_note` | false | 提取时是否发布进度通知 |

## 9.6 cap_scheduler — 调度器

### `cap_scheduler_item_t`

| 字段 | 大小 | 说明 |
|------|------|------|
| `id` | 64 | 唯一调度 ID |
| `enabled` | bool | 是否启用 |
| `kind` | enum | `ONCE`/`INTERVAL`/`CRON` |
| `start_at_ms` | int64_t | 起始时间（Unix 毫秒，ONCE 必填） |
| `end_at_ms` | int64_t | 结束时间（可选） |
| `interval_ms` | int64_t | 周期（INTERVAL 必填） |
| `cron_expr` | 64 | 5 字段 Cron 表达式（CRON 必填） |
| `event_type` | 32 | 触发的事件类型（默认 "schedule"） |
| `event_key` | 96 | 事件关键字 |
| `source_channel` | 16 | 事件来源通道（默认 "time"） |
| `chat_id` | 96 | 目标聊天 ID（可选） |
| `content_type` | 24 | 事件内容类型（默认 "trigger"） |
| `session_policy` | 24 | 会话策略（默认 "trigger"） |
| `text` | 256 | 事件文本负载 |
| `payload_json` | 512 | 结构化 JSON 负载 |
| `max_runs` | int | 最大触发次数（0 = 无限） |

### `cap_scheduler_snapshot_t`

| 字段 | 说明 |
|------|------|
| `item` | 调度定义 |
| `status` | 当前状态（`SCHEDULED`/`PAUSED`/`RUNNING`/`COMPLETED`/`ERROR`/`DISABLED`） |
| `next_fire_ms` | 下次触发时间（Unix 毫秒） |
| `last_fire_ms` | 上次触发时间 |
| `last_success_ms` | 上次成功时间 |
| `run_count` | 已触发次数 |
| `missed_count` | 跳过的触发次数 |
| `last_error_code` | 最近错误码 |

## 9.7 claw_event_router — 路由规则

### `claw_event_router_rule_t`

| 字段 | 类型 | 说明 |
|------|------|------|
| `enabled` | bool | 是否激活 |
| `consume_on_match` | bool | 匹配后停止后续规则 |
| `id` | char[64] | 规则唯一 ID |
| `description` | char[160] | 描述 |
| `ack` | char[256] | 匹配确认日志消息 |
| `vars_json` | `char *` | 规则变量（堆分配 JSON 对象） |
| `match` | struct | 匹配条件 |
| `actions` | `claw_event_router_action_t *` | 动作数组（堆分配） |
| `action_count` | size_t | 动作数量 |

### `claw_event_router_match_t`

| 字段 | 大小 | 说明 |
|------|------|------|
| `event_type` | 96 | 事件类型（必填） |
| `event_key` | 96 | 事件关键字（可选） |
| `source_cap` | 96 | 来源能力（可选） |
| `channel` | 96 | 来源通道（可选，别名 source_channel） |
| `chat_id` | 96 | 聊天 ID（可选） |
| `content_type` | 96 | 内容类型（可选） |
| `text` | 96 | 文本匹配（可选） |
| `text_match_rule` | enum | `EXACT`（默认）或 `PREFIX` |

### `claw_event_router_action_t`

| 字段 | 类型 | 说明 |
|------|------|------|
| `kind` | enum | 动作类型 |
| `cap` | char[64] | CALL_CAP 时的能力 ID |
| `input_json` | `char *` | 输入 JSON（含模板变量，堆分配） |
| `caller` | enum | 调用方类型 |
| `capture_output` | bool | 是否捕获输出 |
| `fail_open` | bool | 失败时继续 |
