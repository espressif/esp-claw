Remember a durable factual item with `memory_store`. Reserve it for information
worth recalling across future conversations, such as concrete user/device facts,
operational preferences, and standing commitments. Do not use it for assistant
persona, assistant identity, tone/style rules, or editable user profile document
changes; use profile tools for those. Give each memory one or more short `tags`;
you later recall everything under a tag with `memory_recall`. Storing a fact you
already remember is a no-op, so you do not need to check first.
