## System overview

The repo follows an **“example app + shared app layer + reusable framework”** layout: `applications/edge_agent` is a buildable ESP-IDF sample that wires Wi-Fi, the config UI, Lua modules, and capabilities into a full device; `applications/shared` holds reusable app wiring, while `framework` holds reusable runtime core, services, capability plugins, and hardware/script extensions.

Today the code falls into four areas:

- **App assembly:** <LinkToSource relativePath="applications/edge_agent/main/" /> and <LinkToSource relativePath="applications/shared/" /> — boot, app wiring, the HTTP provisioning UI, and app-level module registration.
- **Capabilities:** <LinkToSource relativePath="framework/capabilities/" /> — outward-facing capabilities such as IM, MCP client/server, Lua runtime, scheduling, files, time, web search, and more.
- **Runtime core:** <LinkToSource relativePath="framework/foundation/" /> — Agent infrastructure: core context, capability registration, event routing, memory, and skills.
- **Device & script extensions:** <LinkToSource relativePath="framework/lua_modules/" /> — exposes displays, cameras, audio, buttons, GPIO, PWM, storage, and other peripherals to Lua and the Agent.

## Runtime data directory

All runtime data lives under the FATFS mount `/fatfs`:

<FileTree>
- fatfs/
  - sessions/ Session history (one file per session id)
  - memory/
    - MEMORY.md Human-readable memory view (read-only)
    - memory_records.jsonl Structured memory records
    - memory_index.json Summary-tag and keyword index
    - memory_digest.log Memory-operation digest log
    - user.md User profile
    - soul.md Persona
    - identity.md Identity
  - skills/
    - skill_id/
      - SKILL.md Skill metadata and body
      - scripts/ Skill-bundled scripts (optional)
  - scripts/
    - builtin/ Built-in Lua test scripts and libraries
    - docs/ Built-in Lua module docs
    - *.lua Custom Lua scripts
  - router_rules/
    - router_rules.json Automation rules
  - scheduler/
    - schedules.json Scheduler jobs
    - schedules.json.state Scheduler runtime state (generated)
  - static/
    - ESP-Claw.png Example static asset (factory preset)
  - inbox/
    - ... IM attachments
</FileTree>

## Backup and reset

- **Backup**: copy the `/fatfs` subfolders (`sessions/`, `memory/`, `skills/`, `scripts/`, `router_rules/`, `scheduler/`, `static/`, `inbox/`) to external storage.
- **Reset**: re-flash the `storage` partition or re-flash the full firmware.
