---
title: Console usage
description: "Serial debug console status."
---

The legacy C `app_claw` serial CLI has been removed from `applications/shared/app_claw`.

The replacement lives in Rust under `framework/services/debug-console` and
`applications/shared/app-claw`, but it is not wired into the firmware runtime yet.
Until that wiring is added, `edge_agent` does not start an `app_claw` command REPL
by default.
